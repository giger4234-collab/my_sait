# ОРБИТА · веб студия

Длинный красно-чёрный лендинг с авторскими абстрактными 3D-композициями.
Первый экран, три главы с прокруткой, два интерактивных эксперимента,
атлас Земли/Марса/Сатурна, процесс и контакт https://t.me/webdiz3d.

## Запуск

Node.js 22 или новее. В PowerShell из D:\Projects\my_sait:

    npm.cmd ci
    npm.cmd run dev

Открыть http://localhost:3000. Если зависимости установлены, npm.cmd ci не нужен.
Для доверенной локальной сети есть npm.cmd run dev:lan.

## Проверка и статический предпросмотр

    npm.cmd run build
    npm.cmd run typecheck
    npm.cmd run test:export
    npm.cmd run preview

Предпросмотр раздаёт папку out/ по http://127.0.0.1:3000.
Он должен запускаться после сборки. PORT задаёт другой порт.
Это локальный сервер, не публичное размещение.

## Взаимодействия

- Шапка: ВЕБ СТУДИЯ, Telegram, раскрывающееся меню и Escape.
- Сцены реагируют на указатель; доступны пауза и изменение композиции.
- На телефонах 3D включается кнопкой; до запуска показывается лёгкий постер.
- В длинной сцене прокрутка проходит через форму, орбиту и спираль.
- Кнопки 01–03 переходят к главам.
- Атлас сохраняет выбор трёх планет и ссылки NASA.
- Telegram доступен в шапке, финальном блоке и футере.
- При reduced-motion, недоступном WebGL и ошибке сцены остаётся статичный постер.

## Размещение

Next.js экспортирует статические HTML/CSS/JS в out/. Node.js на хостинге не нужен.
Для GitHub Pages в корне домена дополнительный префикс не требуется.
Для адреса username.github.io/my_sait/ перед сборкой задайте:

    $env:NEXT_PUBLIC_BASE_PATH = "/my_sait"
    npm.cmd run build

Префикс применяется к приложению и локальным ресурсам.
Чтобы снова собрать для корня домена, удалите переменную NEXT_PUBLIC_BASE_PATH.
Подготовлен .github/workflows/deploy-pages.yml. Настройка аккаунта и Pages описана в [пошаговом гайде](docs/GITHUB-PAGES.md).
Хостинг должен отдавать файлы out/ и поддерживать HTTPS.

- PRODUCT.md / DESIGN.md — контекст продукта и реализованная дизайн-система.
