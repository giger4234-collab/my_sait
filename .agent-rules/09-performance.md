# Производительность и минимальный вес сайта

Главная цель — отправлять браузеру только то, что действительно нужно пользователю. Начинай с простого HTML/CSS и минимального JavaScript. Не добавляй React, 3D, анимационные библиотеки и крупные UI-наборы, если задача решается проще. Для существующего проекта не устраивай миграцию без измеримой выгоды.

Измеряй, а не угадывай. Проверяй Lighthouse и Core Web Vitals: LCP, INP и CLS. Сначала устраняй крупные изображения, блокирующие ресурсы, лишний JavaScript, скачки макета и медленный сервер.

Оптимизируй изображения и видео, используй responsive images, lazy loading ниже первого экрана и preload только для действительно критичных ресурсов. Ограничивай шрифты и веса. Разбивай код по маршрутам/тяжёлым компонентам, применяй dynamic import там, где это уменьшает начальную загрузку.

Не запускай постоянные анимации, тяжёлые обработчики scroll и ненужные таймеры. Используй passive listeners, requestAnimationFrame для визуальных обновлений и отключай работу невидимых сцен. Кэшируй статические файлы с версионированием. Сжимай ответы на сервере, если это поддерживает хостинг.

Не оптимизируй преждевременно ценой читаемости. После каждой существенной оптимизации повторно проверь функциональность и визуальное качество. Не заявляй о конкретном результате скорости без измерения. -->
