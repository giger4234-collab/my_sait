# Адаптивность и доступность

Разрабатывай mobile-first либо проверяй макет на реальных контрольных ширинах: узкий смартфон, широкий смартфон, планшет, ноутбук и большой монитор. Не ограничивайся механическим уменьшением desktop-макета: меняй композицию, порядок блоков, размеры и поведение элементов.

Проверяй отсутствие горизонтальной прокрутки, обрезанных заголовков, наложений, слишком мелкого текста и элементов, расположенных слишком близко. Кнопки и поля должны иметь удобную область нажатия. Меню должно открываться, закрываться и работать с клавиатуры.

Используй семантические элементы HTML, логичный порядок заголовков, label для полей, alt для содержательных изображений и пустой alt для декоративных. Все функции должны быть доступны с клавиатуры; у интерактивных элементов должен быть видимый focus. Не убирай outline без равноценной замены.

Соблюдай контрастность, не передавай ошибки только цветом и не запускай автоматически звук. Учитывай prefers-reduced-motion. Для модальных окон обеспечивай управление фокусом и закрытие доступным способом.

Проверяй страницу при увеличении масштаба браузера и с длинным/коротким контентом. Адаптивность считается готовой только после проверки основных сценариев на нескольких ширинах.
