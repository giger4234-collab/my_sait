# Архитектура веб-студии

## Основа

Next.js App Router, React, TypeScript, CSS Modules, Three.js и React Three Fiber.
Статический экспорт в out/. Серверные API, формы, БД и авторизация не добавлены.
Новых npm-зависимостей нет.

## Модули

- app: композиция страницы, metadata, локальный Manrope, глобальные токены.
- SiteHeader: ссылка «ВЕБ СТУДИЯ», Telegram, раскрытие меню, Escape и возврат фокуса.
- Hero: главный экран с абстрактной 3D-композицией.
- JourneySections: студия, эксперименты, процесс и Telegram.
- ScrollExperience: длинная закреплённая сцена; прогресс и координаты в ref, React state только для текущей главы.
- PlanetExplorer: сохранённый атлас трёх планет.
- SpaceScene: обнаружение возможностей, мобильный запуск, запасной постер, пауза и seed композиции.
- SpaceCanvas: динамически загружаемый Canvas, свет, монитор кадров и потери WebGL-контекста.
- OrbitalSculpture: параметрическая геометрия, материалы и интерполяция трёх композиций.
- useSceneActivity: IntersectionObserver и видимость вкладки.
- assets.ts: префикс публичных ресурсов для статического размещения.
- scripts/preview.mjs: локальный сервер готовой папки out/.

## Графика и ресурсы

RoomEnvironment и PMREMGenerator создают студийные отражения без внешних HDRI.
Материалы — красный лак и металл. Геометрия создаётся в коде: torus, torus knot,
capsule и sphere. Внешние 3D-модели не используются. Ресурсы сцены освобождаются
при размонтировании.

У каждого видимого эксперимента своя сцена. Canvas монтируется только при
видимости и разрешённой анимации; невидимые участки возвращаются к постеру.
На телефонах пользователь явно включает 3D. DPR ограничен; низкая частота кадров
снижает качество. Пауза включает demand-rendering.

## Прокрутка и доступность

Нативный scroll, passive listener и requestAnimationFrame.
Секции не перехватывают колесо и не блокируют тач-прокрутку.
prefers-reduced-motion отключает анимации, снимает длинное закрепление и
показывает статичные описания глав. Контент и Telegram существуют в HTML
независимо от Canvas.

## Сборка

next build создаёт out/. NEXT_PUBLIC_BASE_PATH задаёт префикс репозитория при
сборке для GitHub Pages. Размещается содержимое out/, не исходные TSX-файлы.

## Проверка экспорта и публикация

scripts/verify-export.mjs проверяет HTML, якоря, шрифты и ресурсы с точным регистром путей. .github/workflows/deploy-pages.yml собирает сайт, проверяет его и публикует out/ через официальные GitHub Actions. Префикс и URL берутся из настроек Pages. Preview поддерживает NEXT_PUBLIC_BASE_PATH.
