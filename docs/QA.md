# Проверка сайта и подготовка к GitHub Pages

Дата: 9 ноября 2026 года. Проверялась принятая владельцем версия веб-студии.
Дизайн сохранён; исправлены ошибки поведения и доступности.

## Исправленные ошибки

- Имя ссылки «Обсудим идею» для вспомогательных технологий теперь включает видимый текст и Telegram.
- Имена кнопок глав включают видимые номера 01, 02, 03.
- Имя кнопки «Изменить форму» совпадает с её видимой подписью.
- На телефонах управление длинной сценой перенесено ниже текста: кнопки больше не накладываются на заголовок.
- На узких и альбомных экранах кнопки первого экрана не выходят за правую границу.
- Локальный preview корректно обслуживает сайт под префиксом /my_sait/.
- Для публикации автоматически формируются canonical и Open Graph по реальному адресу Pages.

## Автоматические браузерные проверки

Playwright Core 1.65.0, установленный Google Chrome, отдельные тестовые профили.
16 сценариев прошли; необработанных JavaScript-ошибок pageerror и ошибок загрузки
ресурсов сайта в этом прогоне не зарегистрировано.

Проверенные размеры:
360 × 800, 390 × 844, 768 × 1024, 1366 × 900, 1920 × 1080,
1366 × 500 и 844 × 390.

- Отсутствие горизонтального скролла и переполнения проверенных заголовков/кнопок.
- Загрузка изображений, включая lazy-ресурсы.
- Меню: Enter, Escape, возврат фокуса, закрытие после выбора ссылки.
- Выбор Марса и Сатурна, смена изображений, данных и источника.
- Live WebGL на компьютере.
- Пауза: снимки Canvas остаются одинаковыми; смена формы меняет снимок.
- Продолжение анимации и переходы между главами.
- Запуск 3D на телефоне по кнопке.
- Синтезированный touch-swipe прокручивает страницу.
- Кнопки живых сцен на 360 × 800, 390 × 844, 1366 × 500 и 844 × 390 остаются в пределах экрана и не перекрывают текст.
- Статичный режим без WebGL.
- Возврат к постеру при искусственной потере WebGL-контекста.
- prefers-reduced-motion сохраняет контент без Canvas.

Скриншоты просмотрены. Данные и снимки находятся в .impeccable/review/
и исключены из Git как временные результаты.

## GitHub Pages

В браузере проверен http://127.0.0.1:3001/my_sait/:
HTML, CSS, шрифт, динамические WebGL-чанки, изображения планет,
меню и якоря работают. Адрес без завершающего слеша перенаправляется на /my_sait/.

Canonical и Open Graph проверены с тестовым адресом example-user.github.io.
В обычном локальном экспорте этот тестовый адрес не используется.
На GitHub workflow возьмёт реальный base_url/base_path из configure-pages.

.github/workflows/deploy-pages.yml проверен YAML-парсером:
main и ручной запуск, зависимость deploy от build, ограниченные права,
существование пяти указанных официальных actions-тегов.

Сам workflow в аккаунте GitHub владельца не запускался. Включение Pages
и первая публичная публикация выполняются по docs/GITHUB-PAGES.md.

## Пределы

Не проверялись физические iPhone/Android, Safari, нагрев, автономность
и реальные полевые Core Web Vitals. Перед широкой публикацией полезен
короткий просмотр на собственном телефоне; после первой публикации —
повторная проверка HTTPS и загрузки по выданному GitHub адресу.
